windows10上Vmware WorkStation Pro17 安装windows7虚拟机

发表于2024-09-02|更新于2024-09-02|Vmware
|阅读量:|评论数:

下载vmware station pro17

  1. 登录博通网站

https://login.broadcom.com/signin

  1. 登录后选择

  1. 在打开的工作台中选择VMware Cloud Foundation，搜索 VMware Workstation Pro

  1. 选择合适的版本，选择个人版

  1. 点击下载

安装VMware WorkStation Pro

一路下一步就行，需要输入密钥的地方，跳过

下载Windows7镜像

MSDN 提供的纯净版下载地址：https://msdn.itellyou.cn/。十五年老网站，还活着！

安装windows7镜像

打开vmware workstation pro

文件->新建虚拟机->典型->

安装程序光盘映像文件选择下载的windows7镜像

默认下一步

命名，自定义文件路径，方便以后迁移

配置虚拟机

启动虚拟机

好，问题开始了。因为本机安装了docker ，会启用windows的Hyper-V，所以，这里会VM会启动侧通道缓解，这就是问题的开始。

1.需要在windows的程序与功能打开windows虚拟机监控平台

这里点确定，windows就开始安装，安装过程没什么好说的，下一步，默认就可以。

2.安装过程中，下方已经出现提示，vm tools不能自动安装

按照提示进入 地址：https://kb.vmware.com/article/78708，页面会跳转https://knowledge.broadcom.com/external/article?legacyId=78708。

这边会告诉你，windows7 sp1和Windows Server 2008 R2 SP1不支持SHA-2，需要手动安装两个补丁。

  • KB4474419
  • KB4490628

在windows的 https://www.catalog.update.microsoft.com/ 下搜索这两个补丁。

选择合适的版本下载。

正常在虚拟机安装好之后，直接用浏览器下载就可以了，但是！

windows7虚拟机不能下载补丁的问题

windows7自带的IE8已经不被支持，想要下载一个其他的浏览器，chrome和firefox官网提供的下载按钮页不能正常访问。

这里进入mozlila官网来下载支持windows7版本的firefox

会提示证书不安全，选择继续浏览

安装好firefox之后，进入 https://www.catalog.update.microsoft.com/ 搜索

  • KB4474419
  • KB4490628

下载并安装。

手动安装 vm tools

如果不安装 vm tools ，默认分辨率就是600*800,如果调整分辨率到1080P，系统就会卡死。这里描述如何手动安装tools:

前提：打好两个两个补丁

挂载镜像

邮件虚拟机，设置，硬件中选择添加CD/DVD驱动

在驱动中浏览选择 VM安装目录下的IOS文件

​

这里选择windows.iso,挂载成功之后，windows7会弹出安装程序，安装

这点击运行，如果这里打补丁，安装驱动会报错：安装程序无法安装vsock

然后回滚，安装失败

安装完成

安装成功之后，重启，调整分辨率

至此，安装成功，可以用来测试之前的老程序。
