1. 安装 corepack

corepack 是 Node.js 16.14+ 版本的一个工具，用于管理 Node.js 包管理器。作为 yarn 和 pnpm 的替代方案，在不同项目中使用不同的包管理器，而无需全局安装多个版本的包管理器。
