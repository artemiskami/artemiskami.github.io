安装git

下载git: https://git-scm.com/downloads/win

安装完成后双击解压

解压后文件：

![1736561791796](C:\Users\artemis\Documents\WeChat Files\wxid_37uow20eb02i22\FileStorage\Temp\1736561791796.png)

配置环境变量

复制 git 解压后路径的bin目录 D:\谷歌下载\PortableGit\bin

此电脑->设置->系统->环境变量

系统变量中的 Path -> 新建

复制git bin 目录

打开控制台，输入git

配置gitlab免密

1.windows 创建用户密钥对

2.复制密钥对

进入目录

记事本打开**id_rsa.pub**复制文本

3.密钥输入gitlab

setting->SSH keys

复制到右侧文本框
